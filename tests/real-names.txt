# Names no test may use: Lee's real projects, his GitHub name, and ids of
# his real sessions and project folders. Samples use placeholders instead:
# Microsoft's fictional companies (Northwind, Contoso, Fabrikam, Tailspin,
# Woodgrove, Litware, Wingtip, Adventure Works, Proseware, Blue Yonder, and
# where more are needed Coho, Humongous, Lucerne, Relecloud, Southridge,
# Alpine, Trey Research, Wide World Importers and VanArsdel, or trey where a
# name must be lowercase), a home of /Users/me, and made-up ids.
#
# The TypeScript kit's tests can't read files, so the app's
# app/Tests/SitRepCoreTests/RealNamesTests.swift applies the rule to both
# suites, and to the prototypes their recordings are made from, and the
# app's own samples are checked against the list too.
#
# Left out: names that are also words the product itself uses. Kit, Portal,
# Mint, Harness, Fabric, Stitch, Folio and Terrace are listed as named, not
# by their lowercase keys; Spaces, Printer, Mac Studio and Handoff not at
# all. The ids listed are the live ones that appeared in the tests, not
# every real id.
#
# The rule:
# - Files: every file under tests/, app/Tests/ and prototypes/ but this
#   one, what is built or installed there (.build, node_modules), the strip
#   recorder's recording.json, which git ignores and the strip's fixtures
#   are made from, and Finder's .DS_Store.
# - Text: the whole text of each file: comments, strings, regexes and
#   fixtures alike.
# - Hit: an entry is a hit wherever it appears, case-sensitively, with no
#   letter or digit directly before or after it. So -, _, ., /, a space and
#   quotes are boundaries: com.leeovery.sitrep is a hit of leeovery.
# - Allow: a line `allow <path> <entry>` exempts every hit of <entry> in
#   that one file, <path> from the repository's root, <entry> the rest of
#   the line, each after a single space. An allow that exempts nothing (its
#   entry unlisted, its file missing, or no hit left in it) fails, as does a
#   line starting `allow` that isn't one, and a list that names nothing.
# - Failing: a hit is told as path:line: entry, and a text file that isn't
#   UTF-8, or a symlinked folder, fails rather than going unread. A file
#   holding a NUL is binary and goes unread, but for UTF-16 opening with its
#   byte order mark, which fails as text that isn't UTF-8.
#
# The format: one entry per line, read trimmed; a line starting with # is a
# comment, and a blank line is nothing.
